# Приложение catalog
Создано приложение под названием catalog, которое зарегистрировано в настройках проекта. Созданы шаблоны главной страницы (home.html) и страницы контактов (contacts.html). Созданы контроллеры для этих страниц. Настроена маршрутизация контроллеров.
Реализована форма обратной связи на странице контактов. Настроена обработка данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных. В приложении каталога созданы модели 
Product и Category. Для них описаны базовые настройки, сформированы фикстуры, создана кастомная команда для добавления тестовых продуктов.
Добавлен в шаблон главной страницы код для отображения списка товаров с помощью цикла. Выделен общий (базовый) шаблон, который включает общие элементы страницы, такие как шапка, подвал и стили. Также создан подшаблон для главного меню, который можно будет включать в другие шаблоны.
